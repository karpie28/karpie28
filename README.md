# Hey, I'm Karol

I build tools that help defenders stay ahead of emerging AI threats. Lead DevOps engineer by day, open-source security tooling builder by night.

## What I'm working on

**[Sundew](https://github.com/sundew-sh/sundew)** — An open-source "carnivorous" honeypot that detects and classifies autonomous AI agents. A persona engine gives every deployment a unique identity, then behavioral fingerprinting scores each visitor — human, scanner, AI-assisted, or fully autonomous — across multiple trap surfaces including MCP servers, REST APIs, and AI-discovery endpoints. Responses are pre-generated at deploy time for zero LLM latency. Built with Python and FastAPI.
