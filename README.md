# Hey, I'm Karol

I build tools that help defenders stay ahead of emerging AI threats. Lead DevOps engineer by day, open-source security tooling builder by night.

## What I'm working on

**[Sundew](https://github.com/sundew-sh/sundew)** — An open-source "carnivorous" honeypot that detects and classifies autonomous AI agents. A persona engine gives every deployment a unique identity, then behavioral fingerprinting scores each visitor — human, scanner, AI-assisted, or fully autonomous — across multiple trap surfaces including MCP servers, REST APIs, and AI-discovery endpoints. Responses are pre-generated at deploy time for zero LLM latency. Built with Python and FastAPI.

## Speaking

- **The Agentic Free Pass: Does an Abliterated Backbone Make Agents Easier to Attack?** — *Upcoming* — DEF CON 34 AI Village (Las Vegas, Aug 2026). Co-presented with Nishith Sinha. Do abliterated models actually make better attackers? We tested base vs. abliterated Qwen3 and Gemma-3 across agentic attack classes: the agentic frame alone breaks alignment on soft attacks (poisoned RAG, malicious skills, MCP tool-poisoning) with no weights changed, while abliteration only matters for genuinely hard content — a divergence we turn into a detector for abliterated models in your stack. Releasing the harness, probe set, and detector.
